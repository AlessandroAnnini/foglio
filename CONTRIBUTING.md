# Contributing

Change the kit, not a generated page.

1. Edit frozen chrome in `skeleton.html`, `index.html`, and `catalog.html` so they stay aligned.
2. Keep slot markup in `catalog.html` as the design specimen. `index.html` is the project page and may use every block. Keep `skeleton.html` slots short.
3. Update `RECIPE.md` when you add a class, a token, or a control.
4. Follow the writing rules in `RECIPE.md`. Source files stay on ASCII.
5. Check `index.html` and `catalog.html` in light, dark, and system. Check 200% zoom. Check a Mermaid expand and close.

Do not minify the frozen blocks. Do not add a build step unless the recipe says so.
