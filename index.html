What

One sheet for any document

Foglio produces one HTML file. Specifications, procedures, meeting notes, use-case maps, training, runbooks, API notes, and research summaries all use the same sheet. You copy skeleton.html, fill the marked slots, and stop. There is no build. Fonts and Mermaid load from CDNs.

Sections are named from the source material. catalog.html is a painted list of allowed blocks, not a required table of contents. If the source has no diagram, omit the diagram. If it has no call to action, omit the buttons.

One file

Open it or send it. Fonts load from Google Fonts. Mermaid 11 loads from jsDelivr. Everything else sits in the file.

Any outline

Ids and labels come from your notes. Do not copy the specimen chapter list unless you are writing a design-system page.

Locked chrome

Fill llm-slot regions only. Style, boot, theme menu, dialog, and runtime stay byte-identical to the skeleton.

Why

The sheet has to stay still

Ask a model for a documentation page and it will invent a stylesheet, a fourth theme, and a typewriter on the first screen. The next run looks different. Captions miss contrast. Body text fills with hollow verbs.

Foglio keeps the sheet still so the model writes titles, sections, tables, and diagrams. A recipe written for any LLM sits in front of your notes. Hosts that cache prompts can reuse that frozen prefix.

Invariant

One file, no build. Copy the skeleton. Fill slots. Apply the writing rules. Stop. Do not restyle, minify, or rewrite frozen chrome.

Getting started

Document a project with an LLM

Install the skill in the project you want to document. Then say: Document this with Foglio. In Cursor, attach @foglio. The skill loads only when you name Foglio. 

npx skills add AlessandroAnnini/foglio

Clone this repository, or copy RECIPE.md and skeleton.html, if you are not using the skill. Add catalog.html only when the model needs to see a painted block.

Name the document type from the source: spec, procedure, notes, map, training, runbook, API notes, or other. Gather the notes, transcript, or file list that belong on the page. Those notes go last in the prompt.

Ask the model to copy skeleton.html to an output path and fill only the llm-slot regions. Do not ask it to write CSS or to start from a blank HTML file.

Features

A closed catalog, three themes

The model picks blocks the document needs and skips the rest. Theme, type, and motion are already decided. Default theme is System: it follows the OS. The choice persists in html-docs-theme.

Blocks

Hero, section, cards, badges, callout, table, prose, buttons, Mermaid, and an SVG flow. Nothing else.

Type

Utopia from 360/18/1.2 to 1240/20/1.25. Inter for reading. JetBrains Mono for labels and code. Prose wraps at 65ch.

Access

WCAG 2.2 AA: body 4.5:1, UI 3:1, 200% zoom, 2.5rem hit areas, visible focus, native dialog for graphs.

Jump

Sticky section links. When the names overflow, the bar becomes a native select. Measure with ResizeObserver.

Mermaid

Version 11 from source text. Tokens pass as hex. Every graph has an expand dialog: X, Escape, or backdrop to close.

Motion

Transform and opacity only, 160 to 400ms. prefers-reduced-motion jumps to the final state in 1ms.

Ink that still reads as accent

Switch Light, Dark, or System in the header. Swatches below repaint from computed tokens. Dark keeps the neon stack. Light keeps 4.5:1 on body and on filled buttons.

Method

How to brief an LLM

Read the source and name the document type: spec, procedure, notes, map, training, runbook, or other. Choose section ids and labels from that material.

Load RECIPE.md first, then skeleton.html. Open catalog.html only when you need to see a painted block. Put project notes after those files so the frozen prefix can be cached.

Ask the model to copy the skeleton to the output path and fill only the llm-slot regions: title, logo, nav, hero, sections, footer. It may set html lang. It must not rewrite style, boot, theme, dialog, or runtime. After it stops, check that #nav-links and #sec-select match every section[id], same order, same labels. Never id a section mermaid.

If chrome drifted, restore the frozen blocks from the skeleton. Do not patch CSS by hand. Do not ask the model to regenerate the stylesheet. For Cursor, VS Code, Claude Code, and chat UIs, start at Getting started.
